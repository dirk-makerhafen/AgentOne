What this page shows
Memory is the durable result of the reflection loop. Each node keeps facts (memory.md), a playbook (reflection.md, injected into sessions when enabled), and an improvement ledger (improvements.md). The Playbook tab shows the rules a session actually sees. Filing a proposal creates a backlog work item; promoting it stays a human decision. This page never runs the walker or applies a change.
